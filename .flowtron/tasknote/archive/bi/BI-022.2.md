## 🎯 Goal

Extract a `PersistenceAdapter` interface from `lib/storage.ts`'s session-persistence functions, make localStorage the default adapter, and re-point `useWorkspace` at the interface — an enabling refactor that keeps local mode byte-identical (existing suite green, no UI change) and gives `BI-022.3`'s Supabase backend a single seam to implement.
