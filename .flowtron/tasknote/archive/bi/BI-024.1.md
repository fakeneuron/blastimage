# BI-024.1 | load-round-ingest

[← PLAN.md](../../PLAN.md) · ✅ Completed · 🔗 [[BI-EPIC-024]] [[BI-021.2]] [[BI-023]]

## 🎯 Goal

Read `imagegen/rounds/r<N>/batch.json` and its on-disk images through the File System Access folder seam, then present each task's batch in the existing review UI — referencing images by path/URL, never embedding them in localStorage.

## ✅ Acceptance

- [x] User can link the host repo's `imagegen/` folder (Chromium FSA) and load a round's `batch.json` + images into the review UI
- [x] Each `batch.json` task maps to a review batch (latest iteration) the existing keep/approve/discard/rate grid can drive
- [x] Generated images are referenced by on-disk path/URL — no base64 slurp into `localStorage` (per `docs/REVIEW-LOOP.md` §5)
- [x] Parse/validation failures and missing image files surface via `UseWorkspace.error`; picker cancel is a silent no-op
- [x] Pure parse/validate logic for `batch.json` is unit-tested; FSA read path has targeted tests (mocked handles)
- [x] Type-checks and lints clean on changed files
