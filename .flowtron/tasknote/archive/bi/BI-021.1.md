**Cross-cutting design decisions (to resolve with the user before filing children):**
1. **Export-bundle mechanism (.2)** — one-file zip (all approved images + `manifest.json`) vs. File System Access folder-write (Chromium-only, writes into `imagegen/approved/`). If zip: add JSZip dep vs. hand-roll a store-only zip (images already compressed; preserves the 3-dep minimalism).

3. **Playbook doc home (.4)** — extend ADOPT.md vs. new dedicated `docs/` doc (operating loop is distinct from ADOPT setup-mechanics and USAGE craft).
4. **Review-sheet generation (.5)** — in-app "Export review sheet" (downloads self-contained HTML from session/manifest) vs. shipped reference script vs. docs-only pattern. May share the manifest schema with .2.
