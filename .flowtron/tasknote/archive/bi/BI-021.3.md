# BI-021.3 | import-builder

[← PLAN.md](../PLAN.md) · 🟢 In progress · 🔗 [[BI-EPIC-021]]

## 🎯 Goal

Add an in-app import-file builder: paste prompts or upload `prompts/*.txt`, preview the resulting tasks, and download a valid `tasks.json` (version 1) — so adopters compose the ⇪ Import bundle in-app instead of hand-rolling a per-repo emitter.

## ✅ Acceptance

- [ ] An in-app affordance (launched near ⇪ Import) lets the user build a task-import file without leaving the app.
- [ ] Upload path: selecting one or more `.txt` files yields one task per file — name = filename (sans `.txt`), basePrompt = file contents.
- [ ] Paste path: pasted text is turned into tasks per the resolved parsing model.
- [ ] A preview shows the resulting `{name, basePrompt}` task list before download.
- [ ] Download emits a valid version-1 `tasks.json` that round-trips through `parseTaskImport` (and the live ⇪ Import).
- [ ] The emitted file parses with zero errors via the existing `parseTaskImport` contract.
- [ ] Type-checks and lints clean; targeted tests cover the new pure parse/emit logic.
