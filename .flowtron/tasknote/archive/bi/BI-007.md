## 🎯 Goal

Implement the mock generation function (themed picsum images) plus the iteration mutation that starts a new round from an updated prompt and an optional primary reference — generation must work from prompt and/or reference, never requiring a reference.

## ✅ Acceptance

- [ ] Mock `generate(...)` produces a batch of `GeneratedImage`s with themed picsum URLs, derived deterministically from the prompt
- [ ] Generation works from prompt-only, reference-only, and prompt+reference inputs; never requires a reference

- [ ] The `useWorkspace` hook exposes a generate action that runs generation, persists the new iteration, and surfaces failures non-fatally
- [ ] `tsc --noEmit` + lint clean; unit tests for the new pure logic pass
