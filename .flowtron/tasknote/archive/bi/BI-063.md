# BI-063 | approve-promote-rollback

[← PLAN.md](../PLAN.md) · ✅ Completed · 🔗 [[BI-032]] [[BI-030.2]]

## 🎯 Goal

When `promoteApproved` fails in `handleImagegenApprove`, roll the image's decision back to its pre-approve value (as the BI-032 conflict-decline branch already does) so session state never claims an approval that never reached `approved/`.

- [x] The conflict-decline rollback (BI-032) still behaves as before — `npx vitest run lib/useWorkspace.test.ts`
- [x] A decision the user changes while the promote is in flight is not overwritten by the rollback (added from External review) — `npx vitest run lib/useWorkspace.test.ts`
