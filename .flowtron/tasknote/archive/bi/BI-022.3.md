**Implementation Notes:**

- **Async seam** (`lib/persistence.ts`): `PersistenceAdapter`'s 8 methods now return Promises; `localStorageAdapter` wraps the sync `storage.ts` calls in `async` (resolved-promise, microtask-fast). The resolved `persistence` const is **config-gated** via `isHostedMode()` → Supabase adapter in hosted mode, localStorage otherwise (local builds never construct the Supabase client).
- **Hook rewrite** (`lib/useWorkspace.ts`): mount effect → async IIFE with a `cancelled` unmount guard; `commit` → optimistic (sync `setSession`/`sessionRef` + background `void (async …)` persist with error surfacing); `createSession` same shape; `switchSession` → async; `generate`'s mid-switch reload branch awaits. The `UseWorkspace` interface is unchanged (`() => void` accepts `() => Promise<void>`). **Behaviour note:** on a (rare) localStorage save failure the optimistic path now shows the unsaved change + the error, where the old sync path kept the prior state — no test pinned this; acceptable for personal-use.
- **Config** (`lib/config.ts`, `lib/supabaseClient.ts`): `NEXT_PUBLIC_BLASTIMAGE_MODE=hosted` + `NEXT_PUBLIC_SUPABASE_URL`/`_ANON_KEY`; lazily-built singleton client.
- **Schema** (`supabase/migrations/20260616000000_init_hosted_schema.sql`): relational mirror — `sessions` + `ref_images`/`tasks`/`iterations`/`generated_images` (denormalized `session_id` + order columns) + `app_settings` (active-session pointer). Every table `owner uuid default auth.uid()` + owner-scoped RLS `for all using/with check (owner = auth.uid())`. FK cascade on delete.
- **Adapter** (`lib/supabaseAdapter.ts`): pure `sessionToRows`/`rowsToSession` mapping (unit-tested) + async `PersistenceAdapter` impl. `saveSession` = upsert + replace-children (sequential, non-atomic — RPC-wrap is a future refinement). Inserts omit `owner` (DB default + RLS enforce). Image bytes stay inline (buckets = `.4`).
- **Supabase config.toml**: ports → **54341–54344** (api/db/studio); analytics/vector/edge_runtime/realtime/inbucket disabled (VM-load trim); auth URLs → `:3003`.
