# BI-048 | file-route-hardening

[← PLAN.md](../PLAN.md) · 🟢 In progress · 🔗 [[BI-045]]

## 🎯 Goal

Harden `app/api/imagegen/file/route.ts` so an unrecognized file extension is refused instead of served as `application/octet-stream`, and add `X-Content-Type-Options: nosniff` to the response.

## ✅ Acceptance

- [x] `contentTypeFor` rejects any extension not in `CONTENT_TYPES` instead of defaulting to `application/octet-stream`
- [x] `GET` responds with a `Result`-shaped 400 (via `resultResponse`) for a rejected extension, without reading the file's bytes
- [x] Successful responses carry `X-Content-Type-Options: nosniff` alongside the existing `Cache-Control: no-store`
- [x] Tests cover both the extension rejection and the new header

## 🧩 Subtasks

- [ ] Change `contentTypeFor` in `app/api/imagegen/file/route.ts` to return `string | null` (null on unrecognized extension) instead of defaulting to `application/octet-stream`, and export it for testing
- [ ] In `GET`, check the result of `contentTypeFor` before calling `readImagegenBytes`; return `resultResponse({ ok: false, error: ... })` on `null`
- [ ] Add `'X-Content-Type-Options': 'nosniff'` to the success-response headers
- [ ] Write `lib/imagegenFileRoute.test.ts`: unit tests for `contentTypeFor`, plus `GET` tests for the rejection (400, no file read) and the `nosniff` header on success
- [ ] Run targeted tests, lint, and type-check

## 🔗 Related
