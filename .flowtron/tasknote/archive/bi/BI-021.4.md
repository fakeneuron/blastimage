# BI-021.4 | review-sheet

[← PLAN.md](../PLAN.md) · 🟢 In progress · 🔗 [[BI-EPIC-021]]

## 🎯 Goal

Add an "Export review sheet" gallery action that downloads a self-contained static `review.html` (embedded image thumbnails + prompt / rating / provenance from the session manifest) so adopters get a repo-durable house-style/consistency pass artifact instead of hand-rolling a per-repo `contact-sheet.html`.

## ✅ Acceptance

- [ ] A third gallery action ("Sheet") sits alongside "Folder" + "JSON"; appears only when there are approved images.
- [ ] The action downloads a single `review.html` that renders standalone (no sibling files, no network) — images embedded as data URLs.
- [ ] Each card shows: thumbnail, task name, star rating, final prompt, and provenance (approved date, references used by name, prompt history).
- [ ] All user/text fields (prompts, names) are HTML-escaped so free-text prompts can't break or inject markup.
- [ ] An image whose fetch fails renders a graceful placeholder cell, keeping its provenance text; the rest of the sheet still lands.
- [ ] A fetch/build failure surfaces via the existing `UseWorkspace.error` channel rather than throwing.
- [ ] Type-checks and lints clean; targeted tests cover the pure HTML-builder + escaping logic.

## 🧩 Subtasks

- [ ] `lib/storage.ts`: add a "Review sheet (BI-021.4)" section — `escapeHtml(s)`, `buildReviewSheetHtml(manifest, embedded: Map<ID,string>)` (pure HTML-doc builder), `gatherReviewImages(manifest)` (async fetch → data-URL map + failed count, mirroring `gatherExportFiles`), and `downloadReviewSheet(manifest)` (orchestrate → `downloadBlob('review.html')`, return failed count).
- [ ] `lib/useWorkspace.ts`: add async `exportReviewSheet()` to the hook + `UseWorkspace` interface; surface partial-fetch/failure via `setError` (mirrors `exportToFolder`).
- [ ] `components/Workspace.tsx`: pass `onExportReviewSheet={ws.exportReviewSheet}` to GalleryPanel.
- [ ] `components/GalleryPanel.tsx`: add a "Sheet" button to the Folder/JSON group (shown when `approved.length > 0`), wired to the new callback.
- [ ] `lib/storage.test.ts`: cover `escapeHtml` and `buildReviewSheetHtml` (embeds passed data URLs, renders prompt/rating/provenance, escapes free text, missing-embed placeholder, empty references).
