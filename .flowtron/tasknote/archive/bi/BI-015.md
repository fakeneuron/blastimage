# BI-015 | batch-generate

[← PLAN.md](../PLAN.md) · 🟢 In progress · 🔗 [[CORE-001.2]]

## 🎯 Goal

Add a "Generate All" action that fires generation across all session tasks simultaneously, producing a cross-task batch for one-pass bulk review.

## ✅ Acceptance

- [x] A "Generate All" button in the sidebar fires generation concurrently for every eligible task (non-empty prompt or ≥1 active reference); ineligible tasks are skipped; the button is disabled while a run is in flight or when no task is eligible
- [x] Concurrent generations never drop each other's iterations — `commit()` keeps `sessionRef` current synchronously (regression test proves two parallel generates both land)
- [x] After firing, the main pane switches to a stacked bulk-review view: one section per fired task (task name + ReviewGrid with full keep/discard/approve/rating/feedback/iterate controls), skeleton grid while that task is still generating
- [x] Selecting a task in the sidebar exits bulk review back to the normal TaskDetail pane
- [x] Per-task failures are non-fatal: successful tasks' batches persist; the error banner surfaces the failure
- [x] `vitest run` green · `npx tsc --noEmit` clean · `npm run lint` clean

## 🧩 Subtasks

- [x] `lib/useWorkspace.ts` — add `generateAll(): ID[]` — collects eligible tasks, fires `generate()` for each concurrently, returns the fired ids
