# BI-068 | safari-focus-restore

[← PLAN.md](../PLAN.md) · 📌 Sidequest (filed 2026-10-18)

## Idea

Safari/WebKit does not focus a button on mouse click, so `useFocusTrap` (`lib/useFocusTrap.ts:66`) captures `<body>` as the opener and restores focus nowhere when a mouse-opened dialog closes. Keyboard-opened dialogs restore correctly. Fix: capture the opener from the pointer target when `activeElement` is `body` (or thread an explicit opener), then drop the `browserName === 'webkit'` guard on the three `opener` focus assertions in `e2e/review-keyboard.spec.ts` and `e2e/iterate-feedback-modal.spec.ts`.
