### Why this exists

Jude wants blastimage to batch-generate short MP4 promo clips (16:9) next to its still batches, using the same flow: generate, keep/approve/iterate, export with a provenance manifest. Done means: approved clips can become `brand/promo-16x9.mp4` (natabula draft spec `.flaitron/specs/brand-video.md`, "promo clip") and can feed Cloutomaton.

### Feasibility

- **Verdict:** Feasible with caveats. **M** size, about 7 tasks (roughly 4–6 agent-days, an estimate), plus one Cloutomaton task.
- **Generation path (verified in the repo):** blastimage uses no API key. `/blast-generate` and `/blast-iterate` run in a Grok Build session using its built-in `image_gen` / `image_edit` (`docs/REVIEW-LOOP.md` §1–2; `docs/GROK-AGENT.md`: "no separate API key is needed"). Video would use Imagine **image-to-video** in the same session, with an approved still as the first frame. Fakeneuron already made its cinema clips this way (`fakeneuron/reference/cinema/GROK-RUN.md`: 16:9, 5–6 s, 720p, first/last frame pinned).
- **Model limits (docs.x.ai video overview, updated 2026-10-08):**
  - Clips run 1–15 s, and the output's aspect ratio follows the input image.
  - `grok-imagine-video-1.5` pins first/last frames but caps at 720p when it does.
  - Lite has no frame pins and upscales to 1080p.
  - Output includes generated audio, which we strip.
- **Cost (corrected):** generation draws on **Jude's Grok subscription**, from the shared weekly usage pool on x.ai/pricing ("covers Chat, Imagine, Voice… refreshes weekly"). There is no per-clip bill. Extra cost comes only from:
  1. an `XAI_API_KEY` in the session, which switches billing to the API;
  2. top-ups after the pool runs out;
  3. a plan without video. x.ai/pricing lists video from Premium ($30) up, and Jude's plan is unknown.
- **API prices, reference only (they apply only with an API key):** per second of output, 1.5 720p $0.14, lite $0.03, base $0.07. At those prices one round of 4 takes × 6 s is about $3.36 on 1.5, and a dozen projects × 2 rounds about $80. **These are not Jude's costs.**
- **Unknown:**
  - video quotas and rate limits on a subscription (xAI publishes none; old Reddit support quotes are anecdotal);
  - the exact Grok Build image-to-video tool name;
  - time per take.

### Solution shape

- Reuse the round pipeline: rounds/, `selection.json`, `approved/` and export are all keyed by filename and slug (`lib/workspace.ts`, `lib/useWorkspace.ts`, `lib/imagegenServerFs.ts`). Add a **separate generation skill** (`/blast-animate`) and a media-aware renderer.
- Never use the in-app data-URL path for video. Base64 in localStorage already corrupted sessions with images (REVIEW-LOOP §5).
- Each take is encoded to the brand spec: H.264 High, `yuv420p`, 1280×720, no audio, `+faststart`, ≤ 4 MB, 4–8 s. A poster frame is extracted.
