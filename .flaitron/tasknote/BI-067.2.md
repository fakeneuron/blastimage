### Why this exists

Sidebar.tsx owns the inline new/rename draft state machine (`openDraft`, `cancelDraft`, `submitDraft`, `handleDraftKey`) and the project ⋯ menu (`openMenuAction`, `menuRef`, `menuButtonRef`). Steps .3 and .4 move that code out. Behavior must be pinned first so the moves are provably behavior-preserving. Sidebar.test.tsx (583 lines) probably pins much of this already; this step adds only the gaps.

### Solution shape

- Add tests only for uncovered behavior. Likely gaps: Enter then blur does not double-submit (the `draftKindRef` guard), Escape cancels without committing, menu closes on outside click and after an action.
- If coverage already pins all of it, drop this step and say so at promotion. Do not file make-work.
