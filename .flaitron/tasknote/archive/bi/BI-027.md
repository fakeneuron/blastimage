# BI-027 | image-lightbox

[← PLAN.md](../PLAN.md) · 🟢 In progress · 🔗 [[BI-005]] · [[BI-008]]

## 🎯 Goal

Click a thumbnail in the review grid or the approved gallery to open the image full-size in a lightbox overlay, with Esc/backdrop-click to close and Left/Right arrows to step through the set.

## ✅ Acceptance

- [x] Clicking a `ReviewGrid` thumbnail opens a full-size lightbox of that image (covers `BulkReviewPane` too — it reuses `ReviewGrid`)
- [x] Clicking a `GalleryPanel` thumbnail opens the same lightbox over the approved set
- [x] Lightbox closes on backdrop click and on Esc; Left/Right arrows step through the set (clamped at the ends)
- [x] Lightbox shows the image `object-contain` (uncropped) within the viewport, mirroring the `FeedbackModal` overlay pattern
- [x] Pure index-step logic lives in `lib/` with a unit test; lint + typecheck + test suite green
