Post-BI-013 ground truth (from `lib/generate.ts`):

- Bridge: `type GrokImagineProvider = (req) => Promise<GeneratedCandidate[]>`; `declare global { var __grokImagineProvider }`. `generateBatch` delegates to `globalThis.__grokImagineProvider`, validates `length === batchSize`, carries prompt provenance, and throws a clear error if no provider is installed.
- FS→data-URL: the agent calls `image_gen` (multiple for batch distinctness), converts filesystem results to `data:` URLs, then installs/replaces the provider before generate runs — so results are self-contained, persist in localStorage like uploaded refs, and render directly.
