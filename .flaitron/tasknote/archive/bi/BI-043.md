# BI-043 | round-reingest-idempotence

[← PLAN.md](../PLAN.md) · 🟢 In progress

## 🎯 Goal

Make round batch ingest idempotent: reloading the same `rounds/r<N>/` must not create duplicate iterations (and thus duplicate gallery/export entries) when disk was rewritten in place.

## ✅ Acceptance

- [x] Re-ingesting the same `batch.round` for an existing task replaces that round's iteration instead of appending a second one
- [x] Ingesting a *new* round number still appends (iteration history preserved)
- [x] Pre-existing duplicate same-round iterations collapse to one on the next load of that round
- [x] Unknown slugs still mint a new task + first iteration (unchanged)
- [x] Unit tests cover replace / append / collapse / mint paths; suite green

## 🧩 Subtasks

- [x] Implement same-round upsert inside `ingestRoundBatch` (`lib/workspace.ts`)
- [x] Extend `ingestRoundBatch` tests in `lib/workspace.test.ts`
- [x] Run targeted + full test suite; typecheck

**Discovery Notes:**

- **Surface:** `lib/workspace.ts` `ingestRoundBatch` always `appendIteration`. Caller: `useWorkspace.loadRound`. Round identity on images: `roundNumberFromImageUrl` / `roundImageUrl` in `lib/imagegenUrl.ts`.
- **Archive:** BI-024.1 shipped append-only ingest as intentional first cut; BI-026 auto-loads latest round on link (amplifies double-load risk); BI-030.3/BI-033 guard rename/delete slug join but not re-ingest.
- **Design choice (PLAN OR):** **Replace** same-round iterations rather than refuse. Matches `/blast-generate` rewrite → reload workflow; refuse would force manual task surgery. Explicit assumption: review decisions on the replaced round's images are intentionally discarded (disk bytes changed). Out of scope: cleaning orphaned `approved/` copies from a prior approve of the rewritten round (BI-030.2 path).
- **Detection:** an iteration "is" round N if any of its image URLs parse to that round via `roundNumberFromImageUrl`. On match: replace first matching iteration's prompt+images; drop any later same-round dups (heal already-duplicated sessions); reindex. No match → append as today.
- **Drift:** PLAN claim matches code; no path/name drift.
- **No clarifications needed.** Assumptions: replace over refuse; pure `workspace.ts` change sufficient (no UI toast required); collapse of pre-existing dups is in-scope kindness on re-load.
