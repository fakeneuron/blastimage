# BI-022.6 | oauth-login

[← PLAN.md](../PLAN.md) · 🟢 In progress · 🔗 [[BI-EPIC-022]] [[BI-022.1]] [[BI-022.3]] [[BI-022.5]]

## 🎯 Goal

Add OAuth (Google/GitHub) login UI + Supabase session wiring on the BI-022.3 adapter, gated to hosted mode — so a hosted-mode user signs in before reaching the workspace, and the per-account session drives the owner-scoped RLS; local mode has no auth and is byte-identical.

## 🧩 Subtasks

1. **Enable OAuth providers in `supabase/config.toml`** — flip `[auth.external.google]` + `[auth.external.github]` to `enabled = true` with env-substitution secrets (`env(SUPABASE_AUTH_EXTERNAL_GOOGLE_*)` / `_GITHUB_*`); `site_url`/`additional_redirect_urls` already point at `:3003`. Add the provider env vars to `.env.example` (commented; local-stack testing only).
2. **Auth module (`lib/auth.ts`)** — hosted-gated helpers over `getSupabaseClient().auth`: `signInWithProvider('google'|'github')` (`signInWithOAuth`, redirect to origin), `signOut()`, and a `useAuthSession()` hook returning `{ session, loading }` driven by `getSession()` + `onAuthStateChange`. Never constructs the client in local mode.
3. **LoginScreen (`components/LoginScreen.tsx`)** — centered full-screen card: "Sign in with Google" / "Sign in with GitHub" buttons calling `signInWithProvider`. Tailwind, matches the neutral shell aesthetic.
4. **AuthGate (`components/AuthGate.tsx`)** — `'use client'`: local mode → render children directly (no client constructed); hosted mode → `useAuthSession()`; loading → neutral shell, unauth → `<LoginScreen />`, auth → children.
5. **Wrap workspace (`app/page.tsx`)** — `<AuthGate><Workspace /></AuthGate>`.
6. **Sign-out + account control in Sidebar** — small account email + sign-out control, rendered only in hosted mode with a live session (returns null in local mode so local UI is byte-identical).
7. **Tests** — `lib/auth` / `AuthGate` behavior: local mode renders children without touching the Supabase client; hosted mode gate flips unauth→login / auth→children (mocked client). Keep the existing suite green.
8. **Verify against local stack** — confirm no other stack running; `supabase start`; admin-API test user → confirm session detection flips the gate + `auth.uid()` resolves for the adapter; `supabase stop`. Live external Google/GitHub hop deferred to [[BI-022.5]].
9. **Lint/type-check + Phase 4** — `tsc --noEmit` + `eslint` on changed files; doc-drift sweep; flip PLAN `.6` to stub; archive.

**Implementation Notes:**

- **Auth helpers** (`lib/auth.ts`, `'use client'`): `signInWithProvider('google'|'github')` → `signInWithOAuth` with `redirectTo: window.location.origin`; `signOut()`; `useAuthSession()` hook seeds from `getSession()` then follows `onAuthStateChange`, with an `active` unmount guard + subscription cleanup. All assume hosted mode; callers gate.
- **Rules-of-hooks split** — `AuthGate`/`AccountControl` branch on `isHostedMode()` in the outer component (no hooks) and call `useAuthSession()` only in an inner `HostedGate`/`HostedAccountControl` that always runs when mounted. So a local build never calls the hook, never constructs the client → byte-identical local mode.
- **Gate** (`components/AuthGate.tsx`): local → children straight through; hosted → loading shell / `<LoginScreen />` / children. Wraps `<Workspace />` at `app/page.tsx` (server component rendering a client gate — valid).
- **Login UI** (`components/LoginScreen.tsx`): centered card, Google/GitHub buttons; pending state clears only on error (success redirects away).
- **Account control** (`components/AccountControl.tsx`): email + sign-out, pinned to the bottom of `Sidebar`; returns null in local mode.
- **Config** (`supabase/config.toml`): `[auth.external.google]`/`[auth.external.github]` `enabled = true` with `env(...)` secrets (+ `skip_nonce_check` for local Google); `site_url`/redirects already `:3003`. `.env.example`: the four provider env vars (commented, local-testing only).
