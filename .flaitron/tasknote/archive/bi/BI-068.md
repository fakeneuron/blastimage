> **Idea** — Safari/WebKit does not focus a button on mouse click, so `useFocusTrap` (`lib/useFocusTrap.ts:66`) captures `<body>` as the opener and restores focus nowhere when a mouse-opened dialog closes. Keyboard-opened dialogs restore correctly. Fix: capture the opener from the pointer target when `activeElement` is `body` (or thread an explicit opener), then add a mouse-open restore e2e.
