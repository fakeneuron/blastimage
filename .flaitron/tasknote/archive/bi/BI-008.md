## 🎯 Goal

Add a right-side gallery panel that auto-collects approved images across all tasks, provides per-item download, and supports bulk export of a JSON provenance manifest.

## ✅ Acceptance

- [ ] Approved images across all tasks auto-populate the gallery panel without user action

- [ ] "Export all" button downloads a JSON manifest with full provenance (matching `ExportManifest` type)
- [ ] Gallery panel shows a friendly empty state when no images are approved yet
- [ ] `tsc --noEmit` + lint clean; unit tests for the two new pure functions pass

**Implementation Notes:**

- **`lib/workspace.ts`** — two new pure read-only functions: `buildApprovedImages(session)` (walks tasks → iterations → images where `decision === 'approved'`, accumulates `promptHistory` per iteration, proxies `approvedAt` from `img.createdAt`) and `buildExportManifest(session)` (calls `buildApprovedImages`, filters `refLibrary` to refs used by approved iterations). Imports `ApprovedImage` + `ExportManifest` from types.
- **`lib/workspace.test.ts`** — 6 new tests in `gallery derivations` describe block: approved-only filtering, empty-session case, multi-iteration `promptHistory` accumulation, manifest session metadata, manifest reference inclusion/exclusion. 31 → 50 total tests pass.
- **`lib/useWorkspace.ts`** — `approvedImages: ApprovedImage[]` derived live (`buildApprovedImages(session)` inline at return; empty array when session is null). `exportAll()` builds the manifest, serializes as JSON blob, triggers a `<a download>` click, and revokes the URL. Both added to `UseWorkspace` interface and the return object.
- **`components/GalleryPanel.tsx`** (new) — right-side panel (w-64), mirrors Sidebar idiom. Header: "GALLERY" label + count badge (visible when >0) + "Export JSON" button (visible when >0). Body: scrollable list of approved image thumbnails (3:2 aspect, `object-cover`), task name, star display (`StarDisplay` helper), and per-item `↓` download button (fetch-to-blob via `downloadImage`, falls back to `window.open` on CORS failure). Empty state when `approved.length === 0`.
- **`components/Workspace.tsx`** — imports `GalleryPanel`; adds it as a third sibling in the `flex min-h-0 flex-1` row after `TaskDetail`; passes `approved={ws.approvedImages}` and `onExportAll={ws.exportAll}`.
