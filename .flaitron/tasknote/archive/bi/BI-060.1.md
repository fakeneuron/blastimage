**Discovery Notes:**

**Design surface inventoried (HEAD `99163c6`):**

- `components/Sidebar.tsx` L478-522 — task list is name + hover-only ✎/🗑; no per-task status. Already receives `currentRound` (L78), so it can derive the visible iteration per task.
- `components/BulkReviewPane.tsx` L44-49 — header is "Bulk review · N tasks" + a hint; no progress, no jump-to-task.

- `lib/types.ts` L46 `ReviewDecision = 'undecided' | 'discarded' | 'kept' | 'approved'`.
- `components/ReviewGrid.tsx` L59-87 — owns the lightbox index; passes only `{src, alt}` to `Lightbox`; card image is `aspect-[3/2] object-cover` (L119), i.e. cropped.
- `components/Lightbox.tsx` — presentational, view-only; ←/→ via window keydown (L45-51), Esc/Tab via `useFocusTrap`. Also consumed by `components/GalleryPanel.tsx` L139 (approved images) — decision controls must be optional so the gallery stays view-only.
- `components/TaskDetail.tsx` L120-174 — name, prompt textarea, ReferenceLibrary, Generate + `generateHint` all render above the grid regardless of mode; in viewer mode (`!generationAvailable`) the grid sits below the fold.
- Only keyboard handlers in the app today: Lightbox arrows, Sidebar ⋯ Esc (L149), draft-name inputs. No URL/router state.

**Archive skim (load-bearing):** BI-027 — lightbox is presentational with index math in `lib/lightbox.ts`; keep that split. BI-053.5 — hid Generate All in viewer mode but **left TaskDetail Generate unchanged**; `.4` deliberately extends that decision to TaskDetail.
