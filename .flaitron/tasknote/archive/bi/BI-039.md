## 🎯 Goal

Apply Lightbox-class focus trap + restore to FeedbackModal, IterateModal, DeleteTaskModal, and ImportBuilder, extracting a shared `useFocusTrap` so four copies collapse to one.

## ✅ Acceptance

- [x] All four modals move focus into the dialog on open and restore focus to the opener on close (any close path that unmounts)
- [x] Tab / Shift+Tab cycle within each dialog's enabled focusables; focus cannot reach the page behind `aria-modal="true"`
- [x] Escape / backdrop / Cancel (and equivalent dismiss controls) still close without writing; existing non-focus behaviour is unchanged
- [x] Shared trap lives in one place (`lib/useFocusTrap.ts`); Lightbox is migrated onto it so the precedent and consumers share one implementation
- [x] Focus coverage added/extended on the four modal test files (and Lightbox stays green); `npm test`, `npm run lint`, `npm run typecheck` green
