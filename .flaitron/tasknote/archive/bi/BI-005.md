# BI-005 | review-grid

[← PLAN.md](../PLAN.md) · 🟢 In progress · 🔗 [[BI-007]] [[BI-006]] [[BI-009]]

## 🎯 Goal

Replace the temporary batch strip with a polished, responsive review grid: per-image cards with keep/discard, star rating, a feedback button, and clear visual states for approved/discarded.

## ✅ Acceptance

- [ ] A new `ReviewGrid` component renders the latest iteration's batch as a responsive grid of image cards (replaces the temporary strip in `TaskDetail`).
- [ ] Each card exposes Keep, Discard, and Approve controls; clicking the active decision clears it back to `undecided`.
- [ ] Each card has a 0–5 star rating control that reads/writes `GeneratedImage.rating`.
- [ ] Each card has a Feedback button wired to a callback prop (modal itself is BI-006).
- [ ] Cards show distinct visual states for kept / discarded / approved / undecided; discarded stays visible but dimmed.
- [ ] Decisions and ratings persist (localStorage) and survive a refresh.
- [ ] Pure mutators `setImageDecision` / `setImageRating` are immutable, target the right image by id, bump `updatedAt`, and no-op on unknown ids; covered by unit tests.
- [ ] `tsc --noEmit` + lint clean; generating skeleton still shows during a round.

## 🧩 Subtasks

- [ ] `lib/workspace.ts` — add a private `updateImage(session, taskId, imageId, patch)` helper (threads task→iteration→image, immutable, bumps task + session `updatedAt`, no-op on unknown ids), then `setImageDecision` and `setImageRating` built on it.
- [ ] `lib/workspace.test.ts` — unit tests for the two mutators (correct image targeted across iterations, immutability, `updatedAt` bump, unknown-id no-op, decision-clear path).
- [ ] `lib/useWorkspace.ts` — expose `setImageDecision(taskId, imageId, decision)` and `setImageRating(taskId, imageId, rating)` actions via the existing `commit` pattern.
- [ ] `components/ReviewGrid.tsx` — new presentational component: responsive card grid for the latest iteration's images; per-card Keep/Discard/Approve, star rating, Feedback button, and visual states.
- [ ] `components/TaskDetail.tsx` — replace the temporary batch strip (keep the generating skeleton) with `<ReviewGrid>`, threading the new callbacks; add the `onFeedback`, decision, and rating props.
- [ ] `components/Workspace.tsx` — wire the new `ws` actions into `TaskDetail` (feedback handler is a placeholder until BI-006).
- [ ] Verify: `tsc --noEmit`, lint, targeted `workspace.test.ts` run, visual confirmation on port 3003.
