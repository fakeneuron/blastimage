# BI-026 | autoload-round

[← PLAN.md](../PLAN.md) · ✅ Done

## 🎯 Goal

After the imagegen folder link and round list resolve, auto-load the latest round into the review UI so a linked session shows its images without a manual **↻ Load round** click. Closes the adopter-UX shortfall where a freshly-generated round (e.g. `rounds/r1/`) leaves the app looking empty until the user clicks Load.

## ✅ Acceptance

- [x] On a linked session with ≥1 round under `imagegen/rounds/`, the latest round loads automatically without a Load-round click
- [x] Auto-load fires at most once per mount and never overrides a round the user has already loaded/switched to (`loadedRound !== null` guard)
- [x] Multi-task rounds open the bulk-review pane, mirroring the manual Sidebar handler
- [x] Lint + typecheck + test suite green

## 🧩 Subtasks

- [x] Trace the link → list-rounds → load-round path (`ImagegenContext`, `useWorkspace`, `Workspace`)

- [x] Resolve `react-hooks/exhaustive-deps` by destructuring the consumed `ws` members
- [x] Run lint / tsc / vitest
